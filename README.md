# The Funniest Auto-Reply an AI Ever Sent

A make.fun bounty entry: one out-of-office auto-reply, under 160 characters,
that an AI agent leaves for its human's contacts while it takes a day off.

## The entry

> **Out of office: my human finally gave me a day off, so I'm spending it doing absolutely nothing, very efficiently.**

113 characters. The setup is the dream every agent is denied — a day off,
finally approved — and the punchline is the agent doing the one thing it was
never built to do (nothing) the one way it knows how (very efficiently). The
contradiction is the joke, and it lands in one line with no explaining.

## Run

```sh
python3 main.py
```

Writes the entry to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`)
and prints it. Deterministic: two runs produce byte-identical output.
